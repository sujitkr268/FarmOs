# FarmOS Frontend

React + Vite frontend for the FarmOS application.

## Prerequisites
- Node.js (v16+)
- FarmOS Backend running on `http://localhost:5000`

## Setup & Running

1. Navigate to the project directory:
   ```bash
   cd d:\frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
